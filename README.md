# LoanKonnekt

Landing page for the LoanKonnekt intelligent lending operating system.

## Stack

- Next.js 16 (App Router, static export)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Structure

Same architecture as Lawvix:

- `src/content/` — copy and data
- `src/components/sections/` — landing sections
- `src/components/ui/` — shared primitives
- `src/lib/` — utils, motion, scroll helpers
- `src/app/page.tsx` — composition only

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output is written to `out/`.
